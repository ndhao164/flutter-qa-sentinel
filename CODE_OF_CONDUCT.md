# Code of Conduct

We want this project to be a welcoming, practical place to collaborate.

Expected behavior includes respectful technical discussion, constructive
feedback, and attention to user/device safety. Harassment, discrimination,
threats, doxxing, and deliberately exposing credentials or private device data
are not acceptable.

Report conduct concerns privately to the repository owner or through GitHub's
private reporting tools. Please do not include secrets or personal data in a
public issue.
